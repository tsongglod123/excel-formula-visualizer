# Project Context

For the full architecture, feature list, tech stack details, and project progress, read the files in `memory-bank/`. These are the single source of truth for all project knowledge:

- `memory-bank/projectbrief.md` — Core requirements, goals, and scope
- `memory-bank/systemPatterns.md` — Architecture, parser design, component tree, styling and testing patterns
- `memory-bank/techContext.md` — Technology stack, dependencies, configuration, deployment, constraints
- `memory-bank/progress.md` — Completed features, in-progress work, planned features, test coverage
- `memory-bank/activeContext.md` — Current work focus, recent changes, next steps
